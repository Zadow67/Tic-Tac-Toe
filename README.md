# Tic Tac Toe

A physical 3D printed Tic Tac Toe board with magnetic pieces and a removable winning stick.

## What you need

### 3D Printed Parts

- 1x Tic Tac Toe base
- 1x winning stick
- 5x O pieces
- 5x X pieces

You should print at least 5 of each piece so both players have enough pieces for a full game.

### Magnets

You will need:

- 4x 4mm x 2mm magnets for the base
- 2x 4mm x 2mm magnets for the winning stick

Make sure the magnets are facing the correct direction before gluing them in.

## Assembly

1. Print all of the parts from the `models` folder.
2. Print at least 5 O pieces and 5 X pieces.
3. Insert 4 magnets into the base.
4. Insert 2 magnets into the winning stick.
5. Check the magnet polarity before permanently attaching them.
6. Once everything is assembled, the board is ready to play.

## How to Play

The game is standard Tic Tac Toe.

1. Choose who plays X and who plays O.
2. Players take turns placing one piece on the board.
3. The first player to get 3 of their pieces in a row wins.
4. The winning stick can be used to mark the winning row.
5. If all 9 spaces are filled without a winner, the game is a draw.

## Files

All of the printable files are located in the `models` folder.

- `base.stl` - Main Tic Tac Toe board
- `winning-stick.stl` - Magnetic stick used to mark the winning row
- `O-piece.stl` - O game piece
- `X-piece.stl` - X game piece

## Printing

The pieces are designed to be printed separately, so you can use different colors for X and O.

No supports should be needed for the basic pieces, but check your slicer's preview before printing.
